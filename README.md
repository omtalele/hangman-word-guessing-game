
# Hangman Word Guessing Game

## Project Overview
Hangman is a simple console-based word guessing game developed using Python.

## Objective
The objective is to guess the hidden word letter by letter within 6 incorrect attempts.

## Features
- Random word selection
- Hidden word display
- Maximum 6 incorrect attempts
- ASCII Hangman drawing
- Tracks guessed letters
- Prevents duplicate guesses
- Displays win or lose message

## Technologies Used
- Python 3
- Random module
- Strings
- Loops and conditional statements
- Functions and sets

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

   python hangman.py

## Game Rules
1. Guess one letter at a time.
2. Correct guesses reveal the letter.
3. Incorrect guesses reduce the remaining attempts.
4. Repeated guesses do not reduce attempts.
5. Guess the word before 6 incorrect attempts to win.
